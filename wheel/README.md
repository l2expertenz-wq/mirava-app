# 🎡 Колесо фортуны Mirava VPN (Telegram Mini App)

Полностью независимый фронтенд интерактивного Telegram Mini App «Колесо фортуны».

## 🌟 Возможности
- **Автономность**: работает полностью независимо от основного веб-приложения подписок Mirava.
- **Поддержка Telegram WebApp SDK**:
  - Автоматически получает `telegram_id`, `username` и `first_name` из `Telegram.WebApp.initDataUnsafe`, сырого `initData`, хэша или query-параметров.
  - Поддержка Haptic Feedback (виброотклик при вращении и выигрыше).
  - Поддержка полноэкранного режима (`expand()`).
- **Связь с боевым бэкендом**:
  - Абсолютный адрес по умолчанию: `https://mirava.dedyn.io:8080`.
  - Эндпоинты: `/api/wheel/status` и `/api/wheel/spin`.
  - Поддерживает переопределение через query-параметр `?api=https://...`.
- **Высокая графика**:
  - Адаптивный Retina High-DPI Canvas с 7 секторами и золотыми LED-индикаторами.
  - Плавная физика вращения с реалистичным торможением (`cubic-bezier`).
  - Праздничный салют конфетти на весь экран при выигрыше.
  - Модальное окно выигрыша с обновлением даты окончания подписки.

## 🚀 Развертывание на GitHub Pages

### Вариант 1: В отдельный репозиторий (например `mirava-wheel`)
1. Создайте новый публичный репозиторий на GitHub (например, `mirava-wheel`).
2. Загрузите файлы из этой папки (`index.html`, `style.css`, `wheel.js`, `.nojekyll`) в корень репозитория.
3. Перейдите в **Settings** -> **Pages** -> выберите ветку `main` (папка `/root`) и нажмите **Save**.
4. Ссылка на приложение будет:
   `https://<ваш_юзернейм>.github.io/mirava-wheel/`
5. В файле `.env` бота укажите:
   ```env
   WHEEL_WEBAPP_URL=https://<ваш_юзернейм>.github.io/mirava-wheel/
   ```

### Вариант 2: В существующий репозиторий `mirava-app` (в подпапку `wheel/`)
1. В репозитории `mirava-app` создайте папку `wheel` и загрузите в неё эти файлы.
2. Ссылка на приложение будет:
   `https://<ваш_юзернейм>.github.io/mirava-app/wheel/`
3. В файле `.env` бота укажите:
   ```env
   WHEEL_WEBAPP_URL=https://<ваш_юзернейм>.github.io/mirava-app/wheel/
   ```
